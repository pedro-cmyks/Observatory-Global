## Recommendation (acceptance: enrichment / defer / reject)

**Query-time enrichment: YES — narrow and async. Bulk ingestion: REJECT.**

The three contexts split exactly along Atlas's need:

1. **High-volume crisis (Sudan)**: 68% of DOC 2.0 results already ingested —
   enrichment is marginal where the firehose already covers. Latency 34.7s.
2. **Market topic**: 0 results in 29s — the DOC 2.0 query parser is fragile
   with OR-groups; wrapper must use simple keyword forms + degrade honestly.
3. **Low-volume signal (Armenia annulment — the fixture class)**: 39 results,
   8 languages, **21/39 NOT in Atlas** — including English (MassisPost),
   Russian analysis, native Armenian press. This is precisely the verified
   depth the 07-04 eval measured as Atlas's gap vs web search.

Design consequence: an **on-demand external-depth lane** in the research
plan / theme detail, triggered only when the topic is thin (gated signals
< ~10), fetched ASYNC (16-35s latency forbids blocking), cached, results
labeled `external · unverified` and passed through the tier map (#217 —
the two ship together: external evidence WITH credibility labels).
Never a firehose; never silent.

Next: wrapper implementation (S/M) — `research_external_depth.py` +
lane_unavailable-style degradation, behind the same honest-gap contract the
semantic lane uses.
